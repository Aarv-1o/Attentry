How it works

Four moments. Otherwise, quiet.

When you ask

The code you already have

Your agent hears which helpers and routes in the repo match your request, so it plans with them.

Attentry: the repo already has code related to this request: - `timeAgo` in src/utils/time.js:1 - GET /api/rides/:id in server.js:11

Before an edit

No second copy

About to write a function the repo already has? Your agent hears where the existing one is.

Attentry: `formatRidePrice`: the repo already has `formatPrice` (src/utils/money.js:2). Import it.

After an edit

Only what this edit added

New problems, once each, in a few lines. A clean edit gets nothing at all; old issues never nag.

Attentry: this edit added 1 problem: socket event "message:delete" loads a record by an id the caller sends without checking it belongs to the caller

At the end

A change card for you

What changed, what it added or fixed, and whether the tests passed. Ten seconds to read.

Attentry change card - Changed: 3 files - Problems: none added - Tests: passed

Get started

Let your agent build. Attentry keeps watch.

  1. Install the extension from the VS Code Marketplace, or from Open VSX for Cursor and Windsurf.
  2. Click Connect Claude Code or Connect Codex in the Attentry panel: it's added for all your projects.
  3. Start a new session and ask for anything. Codex asks you once to trust attentry-hooks: say yes.
