# Attentry brand

The mark is "Watchtower A": the A of Attentry as a tower, its crossbar an eye that watches the
code.

| File | Use |
|---|---|
| `attentry-tile.svg` | App icon: the VS Code Marketplace icon (built to a 128 px PNG), social images |
| `favicon.svg` | Website favicon: heavier strokes for 16–32 px |
| `attentry-mark.svg` | The mark on light backgrounds (site header, docs) |
| `attentry-mark-on-dark.svg` | The mark on dark backgrounds |
| `../editors/vscode/resources/attentry.svg` | VS Code sidebar icon: one colour, the pupil cut out |

Colours: ink `#0E1116`, paper `#F2F4F7`, signal teal `#1FC8A4` (the eye, and nothing else).
Name: "attentry" in lower case, Space Grotesk 600.
